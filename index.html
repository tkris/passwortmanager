⚠️ Sicherheitshinweise

Mehr zur Sicherheit

Änderungen werden vorübergehend verschlüsselt in diesem Browser zwischengespeichert. Deine ursprüngliche .enc-Datei wird dadurch nicht automatisch aktualisiert. Speichere regelmäßig eine aktuelle Datei und prüfe, dass sie auf deinem Gerät vorhanden ist.

Beim Löschen der Browserdaten können noch nicht exportierte Änderungen verloren gehen. Bewahre deine .enc-Datei an einem sicheren Ort auf und verwende ein starkes Master-Passwort. Das Master-Passwort kann nicht zurückgesetzt werden.

Bei eingeschleustem JavaScript oder einem kompromittierten Browser können Passwörter während einer geöffneten Sitzung ausgelesen werden.
